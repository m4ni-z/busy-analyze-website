راهنمای استفاده از پنل

بارگذاری داده‌های ورودی

برای بارگذاری داده‌های ورودی، فایل اکسل خود را از طریق بخش «آپلود فایل» در پنل کاربری بارگذاری کنید.

توجه داشته باشید:
  • فایل باید حتماً با فرمت Excel باشد.
  • نام شیت (Sheet) فایل اکسل باید دقیقاً sp باشد.
  • از صحت و کامل بودن اطلاعات فایل پیش از بارگذاری اطمینان حاصل کنید؛ بارگذاری فایل با فرمت یا ساختار نادرست ممکن است باعث اختلال در پردازش و نمایش تحلیل‌ها شود.

به‌روزرسانی تحلیل‌ها

پس از بارگذاری فایل، داده‌ها پردازش شده و تحلیل‌ها و داشبورد به‌روزرسانی می‌شوند.

فرآیند به‌روزرسانی معمولاً حدود ۶ تا ۸ ساعت از زمان بارگذاری فایل زمان می‌برد.

مشاهده تحلیل‌ها و داشبورد

برای مشاهده تحلیل‌ها و داشبورد، از طریق پنل کاربری وارد بخش «آنالیزها» شوید و گزینه «باز کردن» را انتخاب کنید.

رمز عبور داشبورد نیز در همین بخش نمایش داده می‌شود. در صورتی که رمز عبور به‌صورت مخفی نمایش داده شده باشد، با کلیک روی آن می‌توانید رمز را مشاهده کنید.

پشتیبانی

در صورت ملی شدن اینترنت یا بروز مشکل در دسترسی به پنل، از طریق راه‌های ارتباطی درج‌شده در سایت با پشتیبانی تماس بگیرید.

Panel User Guide

Uploading Input Data

To upload your input data, upload your Excel file through the "File Upload" section in your user panel.

Please note:
  • The file must be in Excel format.
  • The name of the Excel sheet must be exactly sp.
  • Make sure that the file contains complete and accurate data before uploading it. Uploading a file with an incorrect format or structure may cause issues with data processing and analysis display.

Analysis Updates

After uploading the file, the data will be processed and the analyses and dashboard will be updated.

The update process usually takes approximately 6 to 8 hours from the time the file is uploaded.

Viewing Analyses and Dashboard

To view the analyses and dashboard, go to the "Analyses" section in your user panel and click "Open".

The dashboard password is also displayed in this section. If the password is hidden, you can click on it to reveal it.

Support

In case of an internet shutdown or any issue accessing the panel, please contact support through the contact methods provided on the website.
