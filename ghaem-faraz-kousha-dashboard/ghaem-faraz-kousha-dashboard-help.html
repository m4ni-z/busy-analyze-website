راهنمای استفاده از پنل

بروزرسانی داشبورد

داشبورد قرار گرفته روی شبکه شرکت، هر روز به‌صورت خودکار ساعت ۶ بامداد بروزرسانی می‌شود.

بنابراین برای مشاهده آخرین اطلاعات، بهتر است پس از ساعت ۶ صبح وارد پنل شوید و اطلاعات جدید را بررسی کنید.

مشاهده تحلیل‌ها

برای مشاهده تحلیل‌های موجود در پنل، وارد بخش «آنالیزها» شوید و روی گزینه «باز کردن» کلیک کنید.

نام کاربری و رمز عبور نیز در همان قسمت قرار داده شده است و می‌توانید از اطلاعات نمایش‌داده‌شده برای ورود به تحلیل استفاده کنید.

نمایش رمز عبور

در صورتی که رمز عبور به‌صورت تار یا مخفی نمایش داده می‌شود، کافی است روی رمز کلیک کنید تا رمز عبور به‌صورت واضح نمایش داده شود.

پشتیبانی و رفع مشکلات

در صورت بروز هرگونه مشکل در داشبورد، بخش آنالیزها یا SQL Server، و همچنین در صورت مشاهده خطا یا عدم نمایش صحیح اطلاعات، لطفاً با شماره‌های پشتیبانی اعلام‌شده در پنل تماس بگیرید.

Panel Usage Guide

Dashboard Updates

The dashboard available on the company network is automatically updated every day at 6:00 AM.

Therefore, to view the latest information, it is recommended to access the panel after 6:00 AM and check the updated information.

Viewing Analyses

To view the available analyses in the panel, go to the "Analyses" section and click on the "Open" option.

The username and password are also provided in the same section, and you can use the displayed information to access the analysis.

Showing the Password

If the password is displayed as blurred or hidden, simply click on the password to make it clearly visible.

Support and Troubleshooting

If you encounter any problems with the dashboard, Analyses section, or SQL Server, or if you notice any errors or incorrect information display, please contact the support numbers provided in the panel.
